# Semantic Review (v1) - MAKIMA AI Chat UI Polish

**Verdict**: NEEDS_CHANGES

## Summary

The change tightens the MAKIMA AI chat interface to match a desktop/mobile mockup. Avatar shrinks from 96px to 60px (68px mobile), an ONLINE status badge appears below the subtitle, the input bar gets fixed dimensions (52px height, 14px radius, 76px send button) and becomes sticky at z-index 50 with a disclaimer line underneath. Copy is localized to Indonesian. A cache-bust version bump from v2.1 to v2.2 forces browsers to fetch updated assets.

## Issues

### 1. Mobile padding override removes scroll compensation (must fix)

The `@media (max-width: 600px)` rule sets `.makima-ai-messages` padding to `16px 10px`, overriding the `90px` bottom padding that prevents messages from hiding behind the sticky input. On mobile, the last message will be obscured by the input bar.

**Fix:** Add `padding-bottom: 90px` to the mobile `.makima-ai-messages` rule:
```css
.makima-ai-messages {
  padding: 16px 10px 90px;
  gap: 12px;
}
```

### 2. Overflow hidden on input wrap clips focus effects (should fix)

`.makima-ai-input-wrap` has `overflow: hidden` which clips the `box-shadow: 0 0 12px rgba(204, 0, 0, 0.3)` on input focus. This makes the focused state less visible on mobile.

**Fix:** Change `overflow: hidden` to `overflow: visible` on `.makima-ai-input-wrap`.

### 3. Static ONLINE badge with no live state (no action needed)

The badge always shows "ONLINE" regardless of actual backend health. This is purely branding/cosmetic per the mockup requirements, so no action needed.
